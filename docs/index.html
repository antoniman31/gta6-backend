Notifications push — configuration initiale
Le dépôt n'a pas encore de clés de notification. Génère-les ici (elles sont créées dans ce navigateur et ne partent nulle part), puis crée les deux secrets GitHub correspondants.
VAPID_PUBLIC_KEY — secret GitHub
VAPID_PRIVATE_KEY — secret GitHub, à ne jamais partager
Crée les deux secrets dans Settings → Secrets and variables → Actions, puis relance le robot. Cette section disparaîtra et l'abonnement deviendra possible. Ne garde pas de capture d'écran de la clé privée.
Notifications sur cet appareil

Déclenchement à distance (optionnel)
Permet de lancer le robot depuis le téléphone sans passer par l'onglet Actions. Utilise un jeton fine-grained limité à ce seul dépôt, avec la permission Actions : Read and write et une date d'expiration — rien d'autre. Il est stocké uniquement dans ce navigateur, séparément des autres réglages, et n'est jamais inclus dans l'export OPML ni effacé par « Réinitialiser ». Il ne peut pas modifier le code du dépôt.
Version de l'app
Installée sur l'écran d'accueil, l'app ne recharge jamais son propre code : une fois lancée, plus aucune navigation n'a lieu et le fichier HTML servi reste celui du démarrage. Ce bouton force le rechargement sans avoir à fermer l'app. Rien n'est perdu — réglages, articles, lu/non-lu et position de lecture sont conservés.
